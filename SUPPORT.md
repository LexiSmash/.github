# Support

## How to get help or report a problem

This is the **default** support page for any repository under the LexiSmash GitHub organization that doesn't have its own.

- **Found a bug, or a problem with a specific repository** (e.g. a wrong dictionary entry, something broken on the Explorer website, a problem with LexiSmash itself)? Open an Issue in the repository it concerns — [LexiSmash_dictionaries](https://github.com/LexiSmash/LexiSmash_dictionaries/issues) for the dictionary/Explorer, or the [Issues section of this organization](https://github.com/LexiSmash/.github/issues) for anything about the game itself.
- **Found a security vulnerability?** Please don't open a public Issue — see our [Security Policy](SECURITY.md) for how to report it privately instead.
- **General question?** Open an Issue describing what you'd like to know; there's no dedicated forum or chat for this project.

This is a personal, unpaid open source project (see [SECURITY.md](SECURITY.md)): there's no guaranteed response time, but reports and questions are read and answered as time allows.
